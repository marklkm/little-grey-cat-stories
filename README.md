# Little Grey Cat Stories

Starter Bootstrap website.

Features:
- Responsive Bootstrap layout
- Skip link
- Keyboard focus styles
- Increase/decrease/reset text size
- Dyslexia-friendly font toggle
- High contrast mode
- Dark reading mode
- Focus reading mode
- Reading preferences stored in the browser
- Five story cards and starter reader pages

Replace the placeholder covers and illustration blocks with your final images.

- The Cat in the Cemetery now uses the supplied final cover image on both the homepage and its story page.
